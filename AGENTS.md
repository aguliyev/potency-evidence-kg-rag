# Repository guidance

- Put new project documentation in `docs/`, including setup guides, implementation plans, and design notes. Keep the root `README.md` unchanged unless the user explicitly asks to edit it.
- Treat `docs/scratchpad.md` as user-owned. Leave it byte-for-byte unchanged; do not read, edit, move, format, or otherwise process it.
- Follow an explicit user instruction that names a different documentation path for that task.
